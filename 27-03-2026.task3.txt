how would you use the docker run command with -it, -e, -v,and --name

. set an env variable APP_ENV=production
. bind a local directory /app/data to /data inside the container
. name the container my_app



docker run -it -e APP_ENV=production -v /app/data:/data --name my-app ubuntu

production
